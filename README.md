# 🔧 SolidWorks Project Portfolio — Semester 1

This repository contains all SolidWorks projects, assemblies, drawings, and sketches completed during my **first semester** of engineering. It showcases hands-on experience with 3D modeling, part design, assembly creation, and technical drawing using **Dassault Systèmes SolidWorks**.

---

## 🛠️ About SolidWorks

**SolidWorks** is a professional-grade **3D CAD (Computer-Aided Design)** software widely used in mechanical, aerospace, automotive, and product design industries. It allows engineers and designers to:

- Create precise **3D part models** (`.SLDPRT`)
- Build complex **assemblies** of multiple parts (`.SLDASM`)
- Generate **engineering drawings** with dimensions and tolerances (`.SLDDRW`)
- Simulate real-world physics, motion, and stress analysis

SolidWorks is one of the most in-demand CAD tools in the industry, used by companies like Boeing, NASA, Tesla, and hundreds of manufacturing firms worldwide.

## 🏆 Major Projects

### ♟️ Chess Set
A complete **3D Chess Set** modeled from scratch. Every chess piece (King, and 6 sets of pieces) was individually designed and assembled on a full chessboard. This was a collaborative project where each team member modeled specific sets.

### 🚗 Rover
A **Mars Rover-inspired vehicle** featuring:
- Custom main body and front body
- Rocker arm suspension system
- Differential mechanism
- Wheel assembly with tyre and rim
- Boom and bucket hydraulic system

### 🏗️ Wheel Loader
A **Wheel Loader construction machine** with:
- Full vehicle body assembly
- Hydraulic boom and rocker arm
- Bucket attachment
- Differential and axle system
- Environmental scene with road, building, and stones

| `.SLDDRW` | SolidWorks Drawing file — 2D engineering sheet |
